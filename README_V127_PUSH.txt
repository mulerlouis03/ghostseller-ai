COMMANDES À FAIRE APRÈS DÉZIP

1) Ouvre CMD dans le dossier dézippé. Tu dois voir package.json, server.js, public, server, api.

2) Test local:
   npm install
   npm start

3) Push GitHub:
   git add .
   git commit -m "GhostSeller AI V127 REAL COMPLETE"
   git push origin main

IMPORTANT:
Ne lance pas npm install depuis C:\Users\Pc. Il faut être dans le dossier du projet.
